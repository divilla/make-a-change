Backend import graph

Start at cmd/server (package main). Follow arrows down to imports, or expand the tree recursively.
Each package has unique direct imports, unique transitive imports, and reverse links to its importers.

Repository package graph

One node per repository package; every direct repository import is an edge. Shared dependencies stay shared. Click a node to inspect it. Counts include external and standard library imports; “total” means unique direct + indirect imports, excluding the package itself.

Recursive import tree

Expand a triangle to load that package’s imports. Click a package name for its details. Shared packages can appear on multiple paths; counts always deduplicate them. Filtering affects the tree, not counts.

Repository package counts

Files are production Go source files selected for this build. Importers are direct importers within the graph reachable from main. Transitive imports count every reachable package once.
